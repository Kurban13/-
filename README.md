# Республика Дагестан — интерактивная презентация

Презентация о Дагестане: краткая история, народы и языки, народные промыслы,
природа и культура. Сделана как одна HTML-страница без сборки и зависимостей —
достаточно открыть `index.html` в браузере.

**Смотреть онлайн:** https://kurban13.github.io/-/

## Что внутри

| Файл | Что это |
|---|---|
| `index.html` | Интерактивная версия: 3D-предметы, живые фоны, слайды народов |
| `dagestan.pptx` | 19 слайдов PowerPoint 16:9 с переходами по клику на народ |
| `dagestan.pdf` | 19 страниц в формате 16:9 (960×540 pt) — для печати и раздачи |

## Разделы

1. **Страна гор** — титул и ключевые цифры республики
2. **Двадцать веков на Каспийских воротах** — история от Кавказской Албании до наших дней; вехи раскрываются по клику
3. **Народы Дагестана** — 14 народов; клик по имени открывает отдельный слайд с историей, языком и нынешним положением
4. **Ремёсла, у которых есть адрес** — трёхмерная витрина: кубачинский кувшин, балхарская керамика, унцукульская насечка, табасаранский ковёр. Предметы вращаются мышью
5. **Что показывают гостю** — природа и культура; клик по месту меняет фон слайда

В `pptx` и `pdf` работают переходы: клик по названию народа на третьем слайде
открывает слайд этого народа, клик по строке «← НАРОДЫ ДАГЕСТАНА» возвращает обратно.

## Как устроено

- Фоны реальных мест (Каспий, Дербент, Сулакский каньон, бархан Сарыкум,
  Самурский лес, Гунибское плато, Карадахская теснина, горные аулы) рисуются
  на `<canvas>` процедурно — это иллюстрации, а не фотографии
- Трёхмерная витрина — [Three.js](https://threejs.org), геометрия и текстуры
  генерируются в браузере: узор «тутта», роспись ангобом, серебряная насечка,
  ковровые медальоны
- Шрифты — Forum (заголовки) и Golos Text (текст) с Google Fonts
- Работает с клавиатуры: `←` `→` между слайдами, `Esc` — закрыть слайд народа

## Управление

| Действие | Как |
|---|---|
| Следующий слайд | `→` `↓` `Пробел` или прокрутка |
| Слайд народа | Клик по названию народа на третьем слайде |
| Вращать предмет | Тянуть мышью; колесо — масштаб; двойной клик — автовращение |
| Сменить вид на фоне | Клик по месту в списке на пятом слайде |
| Сохранить в PDF | `Cmd/Ctrl + P` → «Сохранить как PDF» |

## Источники данных

Численность народов и доли в населении — по итогам Всероссийской переписи
населения 2021 года, округлённо.
